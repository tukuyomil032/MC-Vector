# ADR-MAP-0007: Java oracle and differential parity

**Status:** Accepted as an execution constraint. **Decision date:** 2026-09-23.

## Decision

The pinned Dynmap Java implementation is the executable oracle for required renderer behavior. Capture fixed inputs and intermediate traces for projection, traversal, model/patch resolution, UV, lighting, shader, alpha and tile boundaries, plus normalized RGBA output and PNG digest. Golden captures are produced before the test run and never generated by the test under verification.

## Consequences

Do not widen tolerances to hide a mismatch. First identify the source symbol/resource and exact operation causing it. Existing four empty-context patch traces are bootstrap evidence only, not full-chunk or pixel parity. Unsupported Java host interfaces may be test adapters; they may not replace renderer algorithms.
