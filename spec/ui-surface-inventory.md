## 使い方

- 受け入れ基準は、このファイルの未チェック（`- [ ]`）が0件になること。
- 各フェーズは、載せ替えた面にチェックを付け、そのコミットに含める。
- 着手前に担当ファイルを rg で洗う（`&&`、三項演算子、`ask(`、`prompt(`、`toast`、`notify`、`openDialog`、`WebviewWindow`、`title=`、`aria-label`）。一覧に無い面が見つかったら、先にこのファイルへ追記してから載せ替える。
- 対象外にした項目は、理由を括弧で書いたうえでチェックを付ける。

## 見つかった不具合

ユーザー決定: このブランチで全部直す。1件につき1つの `fix:` コミットにし、載せ替えのコミットとは混ぜない。修正したらここにチェックを付ける。再現と修正は `/systematic-debugging` の作法で原因を先に特定し、可能な限りテスト（vitest または e2e）で確かめる。

### データが消えるもの

- [ ] プロパティの読み込みに失敗した後で保存すると、初期値で上書きされる
- [ ] 全般設定の編集中にサーバーの状態が変わると、編集内容が消える
- [ ] プロパティと全般設定に、未保存の確認と変更検知が無い
- [ ] トークン変更をキャンセルすると、トークンが消える

### 確認が無い

- [x] 復元に確認が無い
- [x] ユーザーの削除に確認が無い
- [x] アプリ終了時に動いているサーバーの停止に確認が無い（終了前に確認を出す）

### 表示の誤り

- [ ] ウィザードのバックアップの進捗が 10000% になる
- [x] アップデートが 100% のまま止まる
- [x] 再起動待ちの状態が表示されない
- [x] Java のダウンロード状態が一度も設定されない
- [x] ヘッダーの見出しが重複している

### 状態の不整合

- [ ] 停止中でもコマンドを送れる
- [x] 起動の条件がヘッダー（クラッシュ時も起動可）とパレット、ショートカット（オフライン時のみ）で違う
- [x] サイドバーを折りたたむと、設定とサーバー追加に行けなくなる
- [x] 設定の「戻る」が常にダッシュボードに戻る

### 閉じられてしまう

- [ ] ウィザードがバックアップやダウンロードの途中でも閉じる
- [x] Java 管理がダウンロード中でも × で閉じる
- [x] アップデートのキャンセルで閉じてもダウンロードが続く

### その他

- [ ] コンソールのアドレスをコピーしても反応が無い
- [ ] 解凍で zip 以外を選んでも成功と表示される
- [ ] 差分の読み込みエラーを捕まえていない
- [ ] 選択ウィンドウで、エラーと空の区別が無い
- [ ] 選択ウィンドウで、適用の失敗を通知しない
- [ ] バイナリや大きなファイルをエディタで開いたときの状態が無い
- [ ] プラグインの配布元を切り替えたときに、前の結果が残る
- [ ] 確認ダイアログを出している間も、「インストール中」と表示される
- [ ] ソフトウェアの一覧に NeoForge が無い
- [x] インポートで、ポートとメモリが固定値になっている
- [ ] 自動再起動と自動バックアップの子項目が、オフのときも編集できる
- [x] アップデートの通知が起動するたびに毎回出る。後で、またはスキップする手段が無い
